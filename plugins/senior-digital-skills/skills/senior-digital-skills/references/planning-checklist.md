# Class planning checklist

Work top to bottom. Dates are relative to the first session; adjust to the partner's calendar.

## 8+ weeks before

- [ ] Partner and payer agreed in principle; contact person named.
- [ ] Learner group described: age range, phones (iPhone / Android mix), languages, accessibility needs.
- [ ] Goals agreed: which tasks learners should be able to do; what the partner wants reported.
- [ ] Modules chosen from the [curriculum](curriculum.md); session count and length set.
- [ ] Costed with the [cost sheet](pricing-and-costs.md); quote or proposal sent.
- [ ] Funding leads checked on official pages, with the date checked recorded
      ([funding and partners](funding-and-partners.md)).
- [ ] Contract, insurance certificate, background checks and any registration the partner needs.

## 4-6 weeks before

- [ ] Venue booked; room checklist confirmed ([teaching guide](teaching-older-adults.md#room-checklist)).
- [ ] Wi-Fi tested for the expected number of devices; power strips available.
- [ ] Local specifics confirmed: which parking/transit apps the town uses, local scam patterns,
      local help contacts.
- [ ] Promotion started (flyers, library and senior-center calendars, phone sign-up line). Use the
      marketing events skill if installed.
- [ ] Helpers recruited and booked.

## 1-2 weeks before

- [ ] Step cards written and tested on current iPhone and Android phones; large print; dated.
- [ ] Practice QR codes, demo menu page and sample passes working.
- [ ] Instructor demo accounts ready; no learner accounts used for demos.
- [ ] Helper briefing on [learner safety](learner-safety.md) done and signed.
- [ ] Pre-class confidence form printed ([outcomes](outcomes.md)).
- [ ] Reminder calls or texts to registered learners, with what to bring (charged phone, charger,
      glasses, hearing aids, and their own password notebook if they use one, kept private;
      app-store and Wallet steps need the learner's own password or Face ID / fingerprint).

## Each session

- [ ] Arrive early; test Wi-Fi, projector, power.
- [ ] Sign-in; accessibility setup for new learners.
- [ ] Demo, guided practice, break, independent try, recap card.
- [ ] Observed task checks recorded; incidents noted.
- [ ] Notes on what to change next session.

## After the course

- [ ] Post-class confidence form and satisfaction questions.
- [ ] 30-day check-in if agreed.
- [ ] One-page results report to the partner; invoice.
- [ ] Sign-in sheets stored or shredded per the agreed retention period.
- [ ] Step cards updated for menu changes; lessons learned recorded for the next cohort.
