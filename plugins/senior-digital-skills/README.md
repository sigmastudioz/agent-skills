# Senior Digital Skills Class

By **[Lex from SigmaStudioz](https://github.com/sigmastudioz)** · MIT · version 1.0.0.

Plan, fund, run and measure a small, hands-on digital-skills class for older adults. Learners
practise on their own phones and leave able to do everyday tasks unaided: read the screen
comfortably, scan a QR-code menu, use the local parking or transit app, show a wallet pass or
ticket, find store-app deals and decide what data to share, join a video call, send a photo and
spot a scam.

The skill provides curriculum modules, a session shape and teaching moves for older learners,
accessibility settings to teach, learner-safety boundaries (instructors never handle passwords,
PINs, codes or payment details), a pre/post outcomes kit, a cost sheet with no invented rates,
funding and partner leads to verify on official pages (New Jersey and national), and a planning
checklist. It links to neighbouring skills for grant writing, proposals, event promotion and
deeper anti-phishing material instead of duplicating them.

## Install

`npx skills add sigmastudioz/agent-skills --skill senior-digital-skills`

In Claude Code: `/plugin install senior-digital-skills --marketplace sigmastudioz/agent-skills`

Guidance only: no executable helper, tracker, account or required service. It never submits
applications, signs contracts or contacts funders. Funding programmes change; each lead must be
checked on its official page when used.
