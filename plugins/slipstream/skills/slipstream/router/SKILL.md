# Skill Library

Loading this skill is step 0, not the answer: search and read the specific skill before replying.
Specialist skills live in a catalog instead of the always-loaded listing, so they cost nothing
until needed. They work exactly like installed skills once read.

1. Search with 3–6 task words (domain, tool, action):
   `python3 <this skill dir>/scripts/find_skill.py "kerberoasting detection splunk"`
2. Pick the best match by description. If nothing fits, rephrase once with synonyms.
3. `Read` the chosen SKILL.md path in full and follow it as if it had been invoked. Resolve its
   relative links against that file's folder.
4. Tell the user in one line which skill you loaded. If no skill fits, continue without one.

Skip this when a listed skill already covers the task.
