# Coding support after an invention

This is an adoption note, not a second general coding workflow. Use the project's existing engineering
instructions for ordinary fixes, ownership, tracing and verification. The invention entry is
[invention methods](invention-methods.md).

Once a proposed mechanism survives its decisive check, connect it through the public caller and terminal
consumer. Keep a working slice, preserve supported contracts and test the boundary that distinguishes it
from the baseline. Check that old expansion, repeated work or stale assumptions did not survive in an
adapter, presenter or fallback. Record what changed and what remains unproven in the existing project
record. A routine task that needs no invention can finish directly under the ordinary workflow.
